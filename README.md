# 🚀 My First Portfolio Website

This is my first portfolio website that I made while learning web development!

I wanted to create a website about myself where I could introduce myself, show my skills, list my projects, and add my contact details. So, I used HTML and CSS and tried to put everything together into one simple webpage.

It might not be the fanciest portfolio out there, but it was one of my first attempts at making something of my own with code. And honestly, that felt pretty cool!

## 🌐 What does it have?

- **About Me:** A small introduction about myself and my interests.
- **Skills:** A list of the programming languages and skills I was learning.
- **Projects:** A place to show the projects I had made.
- **Contact Me:** Links to my email and LinkedIn profile.
- **Simple Design:** A clean layout with a dark header, light background, and a few buttons.

And, of course, my original tagline: *Web Developer | Tech Enthusiast | Future Trillionaire 🚀*

## 🛠️ Technologies Used

- HTML
- CSS

I used HTML to structure the webpage and CSS to style it, including the colors, spacing, profile picture, buttons, and different sections.

## 📸 What I Learned

Making this website gave me my first experience with:

- Creating a webpage using HTML.
- Styling elements with CSS.
- Organizing a page into different sections.
- Adding images, links, and buttons.
- Using basic CSS hover effects.
- Putting my own information into a website.

## 💭 Looking Back

This portfolio was a small beginning for me.

At that point, I was still learning the basics and figuring out how websites worked. I didn't have a huge tech stack or complicated tools. I just wanted to make a website that introduced me to the world.

Looking at it now, I can see how simple it was, but that's what makes it special. Every developer has a starting point, and this was one of mine.

There was a time when even making a simple portfolio felt like an achievement. I'm glad I started somewhere.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. That's it! 🎉

No frameworks, no installations, and no complicated setup required.
